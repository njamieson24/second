# Second starter kit

Drop everything in this folder into an empty project folder (or a new GitHub repo), then open Claude Code there.

- `CLAUDE.md` : Claude Code reads this automatically at the start of every session.
- `docs/PRODUCT.md` : what Second is and what each mode does.
- `docs/DESIGN.md` : colors, fonts, components, logo rules.
- `docs/BUILD_PLAN.md` : the phases, with the exact prompt for Phase 1.
- `design/screens/` : screenshots of every approved screen.
- `design/html/` : the HTML behind each screen, so Claude can read exact spacing and colors.
- `design/brand/` : logo files.

Start with Phase 1 in docs/BUILD_PLAN.md.
